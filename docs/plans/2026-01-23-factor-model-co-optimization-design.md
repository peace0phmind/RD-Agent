# 因子-模型联合优化设计方案

**创建时间**: 2026-01-23
**目标**: 在Qlib框架下，通过RD-Agent自动化演化，同时优化因子和模型以达到IC > 0.11、年化收益 > 5%、回撤 < 10%的目标

---

## 一、问题背景

### 当前状态
- **最佳因子**: Price_Distance_Z_5D/10D/20D (IC: 0.102, +3.75%)
- **核心问题**: IC提升未转化为实际收益（年化-2.42%）
- **现有模型**: LightGBM (SOTA baseline)

### 目标指标
| 指标 | 当前值 | 目标值 |
|------|--------|--------|
| IC | 0.102 | **> 0.11** |
| 年化收益率 | -2.42% | **> 5%** |
| 最大回撤 | 0.00% | **< 10%** |
| 跨期稳定性 | 待验证 | **全周期稳定** |

---

## 二、技术方案对比

### 方案A：迭代式Co-optimization (推荐) ✅

**核心思路**: 因子和模型交替演化

```
Phase 1: 固定SOTA模型 → 3-5轮因子演化
   ↓
Phase 2: 固定最佳因子 → 5轮模型演化
   ↓
Phase 3: 评估 → 决策: 收敛 or 继续Phase 1
```

**优点**:
- 计算效率高（避免全空间搜索）
- 因子和模型各自充分优化
- 易于调试和追踪问题来源
- 符合RD-Agent原生设计

**缺点**:
- 可能错过某些因子-模型特殊组合
- 演化顺序可能影响最终结果

**预计耗时**: 2-3小时（15-20轮演化）

---

### 方案B：同步联合演化

**核心思路**: 每轮同时生成新因子和新模型

```
每个Loop:
  - Research Agent: 同时提出新因子假设和新模型假设
  - Development Agent: 实现并测试新组合
  - 评估反馈 → 进入下一轮
```

**优点**:
- 理论上能找到全局最优组合
- 因子和模型协同演化

**缺点**:
- 搜索空间巨大，计算成本高
- 难以判断是因子还是模型带来的提升
- 需要更多演化轮次才能收敛（30+轮）

**预计耗时**: 4-6小时

---

### 方案C：分层演化

**核心思路**: 先因子后模型，再微调

```
Phase 1: 固定LightGBM → 20轮因子演化
   ↓
Phase 2: 固定最佳因子 → 10轮模型演化
   ↓
Phase 3: 手动调优超参数
```

**优点**:
- 步骤清晰，易于理解
- 每阶段充分优化
- 可控性强

**缺点**:
- 忽略了因子-模型的交互效应
- 前期固定模型可能限制因子探索方向
- 依赖人工调优经验

**预计耗时**: 3-4小时

## 三、选定方案：方案A实施细节

### 3.1 整体流程

```
┌─────────────────────────────────────────────────────┐
│  Phase 1: 因子预探索 (Loop 1-5)                      │
│  - 模型: 固定LightGBM (SOTA配置)                     │
│  - 目标: 寻找IC > 0.11的因子组合                      │
│  - 策略: 从Price_Distance_Z基线开始扩展              │
└─────────────────────────────────────────────────────┘
                          ↓
              IC是否提升 > 2%？
                          ↓
                    ┌────┴────┐
                   No        Yes
                    ↓          ↓
              调整因子策略   继续Phase 2
                          ↓
┌─────────────────────────────────────────────────────┐
│  Phase 2: 模型优化 (Loop 6-10)                       │
│  - 因子: 固定Phase 1最佳因子                         │
│  - 目标: 提升收益率到 > 5%                           │
│  - 模型候选: LightGBM, MLP, HIST, TRA               │
└─────────────────────────────────────────────────────┘
                          ↓
              收益率是否转正？
                          ↓
                    ┌────┴────┐
                   No        Yes
                    ↓          ↓

                          ↓
┌─────────────────────────────────────────────────────┐
│  Phase 3: 联合微调 (Loop 11-15)                      │
│  - 同时微调因子权重和模型超参数                       │

│  - 策略: 贝叶斯优化或网格搜索                        │
└─────────────────────────────────────────────────────┘
                          ↓

                          ↓
                    ┌────┴────┐
                   No        Yes
                    ↓          ↓
               迭代或停止     生成最终报告
```

### 3.2 Phase 1: 因子演化策略

**起始点**: 已验证的Price_Distance_Z因子 (IC: 0.102)

**演化方向**:

1. **多时间窗口组合**
   - 扩展到3D、5D、10D、20D、60D
   - 使用多个Z-Score因子的加权组合

2. **交互项因子**
   ```
   - Price_Distance_Z × Volume_Ratio
   - Price_Distance_Z × Volatility
   - Z_5D - Z_20D (短期-长期Z差分)
   ```

3. **市场状态识别因子**
   ```
   - Trend_Strength = |Z_5D| + |Z_10D| + |Z_20D|
   - Market_Regime = 切分趋势/震荡市场
   ```

4. **风险调整因子**
   ```
   - Sharpe_Ratio_5D/10D/20D
   - Max_Drawdown_20D
   ```

**成功标准**:
- IC > 0.11
- IC_IR > 0.5 (稳定性)
- 因子数量 ≤ 10 (避免过拟合)

---

### 3.3 Phase 2: 模型优化策略

**固定因子**: Phase 1最佳组合

**模型候选集**:

| 模型 | 特点 | 适用场景 | 优先级 |
|------|------|----------|--------|
| **LightGBM** | 当前SOTA，梯度提升 | 稀疏特征，快速训练 | 高 |
| **MLP** | 神经网络，非线性能力 | 复杂交互项 | 中 |
| **HIST** | 直方图集成，超宽 | 高维特征 | 中 |
| **TRA** | 时序关系感知 | 时序依赖强 | 低 |
| **LSTM/GRU** | 循环神经网络 | 时序记忆 | 低 |

**超参数优化范围**:
```python
LightGBM:
  - learning_rate: [0.01, 0.05, 0.1]
  - num_leaves: [31, 63, 127]
  - max_depth: [5, 7, 10]
  - feature_fraction: [0.7, 0.9, 1.0]
  - bagging_fraction: [0.7, 0.9, 1.0]
  - bagging_freq: [1, 5, 10]

MLP:
  - hidden_size: [64, 128, 256]
  - num_layers: [2, 3, 4]
  - dropout: [0.1, 0.3, 0.5]
  - learning_rate: [0.001, 0.0001]
```

**成功标准**:
- 年化收益率 > 5%
- 最大回撤 < 10%
- IC保持 > 0.10

---

### 3.4 Phase 3: 联合微调策略

**目标**: 在IC和收益率之间取得最佳平衡

**优化方法**:

1. **因子权重优化**
   ```
   - 等权 → 优化权重
   - 目标函数: IC × w1 + 收益率 × w2 - 回撤 × w3
   ```

2. **模型集成**
   ```
   - Soft ensemble: LightGBM + MLP
   - Stacking: 二层模型学习最优组合
   ```

3. **交易成本优化**
   ```
   - 增加信号阈值，减少交易频率
   - 仓位管理: 根据信号强度分配权重
   ```

**成功标准**:
- 同时满足所有四项指标
- 跨2017-2020四个年度均达标

## 四、评估指标体系

### 4.1 预测能力指标

| 指标 | 计算方式 | 目标 |
|------|----------|------|
| IC (Information Coefficient) | rank(因子, 未来收益) | **> 0.11** |
| IC_IR (IC/Std(IC)) | IC稳定性 | **> 0.5** |
| Rank IC | Spearman相关 | **> 0.10** |

### 4.2 盈利能力指标

| 指标 | 计算方式 | 目标 |
|------|----------|------|
| 年化收益率 | (最终收益/初始收益)^(365/持有天数) - 1 | **> 5%** |
| 累计收益 | 各期收益求和 | 正值 |
| 超额收益 | 策略收益 - 基准收益 | **> 3%** |

### 4.3 风险指标

| 指标 | 计算方式 | 目标 |
|------|----------|------|
| 最大回撤 | max(峰值 - 谷值) / 峰值 | **< 10%** |
| 波动率 | 收益率标准差 | < 20% |
| Sharpe比率 | (年化收益 - 无风险率) / 波动率 | **> 0.5** |

### 4.4 稳定性指标

| 指标 | 计算方式 | 目标 |
|------|----------|------|
| 跨年度IC变异系数 | Std(各年度IC) / Mean(各年度IC) | **< 0.3** |
| 月度胜率 | 盈利月数 / 总月数 | **> 55%** |
| 连续亏损月数 | 最大连续亏损月数 | **< 3** |

## 六、风险与应对

### 6.1 潜在风险

| 风险 | 影响 | 概率 | 应对策略 |
|------|------|------|----------|
| Phase 1因子无显著提升 | 浪费时间 | 中 | 设置止损条件(5轮后IC < 0.105则调整策略) |
| 模型训练过拟合 | 回测失效 | 中 | 严格验证集监控，早停机制 |
| 计算资源不足 | 实验中断 | 低 | 使用checkpoint机制，支持断点续训 |
| 收益率无法转正 | 未达目标 | 高 | Phase 3增加交易成本优化模块 |

### 6.2 止损条件

如果以下情况发生，提前终止并调整方案：
- **Phase 1**: 5轮后IC < 0.105 → 尝试方案B或C
- **Phase 2**: 5轮后收益仍 < 0% → 引入新因子类型
- **Phase 3**: 3轮后无改善 → 人工干预调整
